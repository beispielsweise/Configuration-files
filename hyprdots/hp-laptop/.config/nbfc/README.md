# Custom config for Laptop model "HP Elitebook 850 G2"
1. Install ```nbfc``` by running ```yay -S nbfc```
2. Run ```sudo systemctl start nbfc``` to start system service, check by running ```systemctl status nbfc```
3. Copy the config from this directory to ```/opt/nbfc/Configs/```
4. Run ```nbfc config -a "HP Elitebook 850 G2"``` to insta apply fan curve config
